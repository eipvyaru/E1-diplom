# Описание настроек тестирования
## 1. Выполните начальные настройки обслуживания клиентов в информационной базе
Инструкция по настройке находится по [ссылке](https://github.com/eipvyaru/E1-diplom/blob/main/README.md#%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B0--%D0%BE%D0%B1%D1%81%D0%BB%D1%83%D0%B6%D0%B8%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F-%D0%BA%D0%BB%D0%B8%D0%B5%D0%BD%D1%82%D0%BE%D0%B2)
## 2. Выполните настройки окружения для запуска автоматизированных тестов
### 2.1.  Проверьте наличие и при отсутствии добавьте учетные записи пользователей:
- "Администратор" с полными правами доступа
- "Менеджер" с правами доступа права доступа "Менеджер"
- "Специалист" с правами доступа права доступа "Специалист"
- "Бухгалтер" с правами доступа права доступа "БухгалтерИТФирмы"
### 2.2. Добавьте в справочник "Расчет управленческой зарплаты\Сотрудники" сотрудника  "Специалист"
### 2.3. Загрузите файлы по [ссылке](https://github.com/eipvyaru/E1-diplom/tree/main/autotest) и полключите к библиотеке VanessaAutomation.
## 3. Для тестирования запускайте файл "E1-diplom-struct1.feature"
