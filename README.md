# Инструкция по начальной настройке

## Первый запуск

Первый запуск клиентского приложения выполнить с параметром запуска "/ЗапуститьОбновлениеИнформационнойБазы"

## Настройка  обслуживания клиентов

### Настройка констант
1. Добавьте в справочник Номенклатуры позиции "Абонентская плата" и "Работа специалиста" с видом номенклатуры "Услуга"
2. Задайте указанные позиции в константах "Номенклатура абонентская плата" и "Номенклатура работы специалиста" соответственно, которые находятся в "Обслуживание клиентов\Сервис"  

### Заполнение НСИ
1. Добавить  в справочнике "Покупки и продажи\Справочники\Контрагенты" в  "Договоры контрагентов" договоры обслуживания клиентов с видом "Абонентское обслуживание". Заполнить стоимость ежемесячного обслуживания и стоимость часа работу специалиста.
2. Заполнить справочник "Обслуживание клиентов\Справочники\Сотрудники"

### Права доступа
1. Добавить пользователям, управляющим обслуживанием клиентов, права доступа "Менеджер".
2. Добавить пользователям, выполняющим обслуживание клиентов, права доступа "Специалист".
3. Добавить пользователю, ведущему бухгалтерский учет обслуживания клиентов и взаиморасчеты , права доступа "БухгалтерИТФирмы".

### Интеграция с Телеграм

#### Документация

Документация по интеграции с Телеграм опубликована по [ссылке](https://core.telegram.org/bots/api). Инструкция ниже сформирована на основании этой документации.

#### Подготовка

##### Создание бота

1. Напишете в Телеграм [https://t.me/BotFather](BotFather) команду "/start"
2. Напишите команду "/newbot"
3. Выберите имя вашего бота, которое будут видеть пользователи
4. Выберите идентификатор вашего бота (он должен заканчиваться на "bot")
5. Скопируйте токен, который пришлет BotFather и сохраните его в константу "Обслуживание клиентов\Сервис\Токен Telegram бота"

##### Создание группы

1. Создайте группу в Телеграм
2. Добавьте в группу только что созданного бота
3. Назначьте боту права администратора

##### Получите идентификатор группы

1. Напишите любое сообщение в группу
2. С помощью браузера или Postman выполните запрос `https://api.telegram.org/bot[ВашТокен]/getUpdates`. В полученном JSON найдите идентификатор группы, в которой получено сообщение, и сохраните его в константу "Обслуживание клиентов\Сервис\Идентификатор группы Telegram: chat_id".

   
## Настройка управленческой зарплаты

### Заполнение НСИ
1. Заполнить справочник "Расчет управленческой зарплаты\Справочники\Графики работы". Заполнить обработкой "Расчет управленческой зарплаты\Сервис\Заполнение графика" каждый график работы на текущий год.
2. Заполнить справочник "Расчет управленческой зарплаты\Справочники\Сотрудники"
3. Ввести для каждого сотрудника документ "Расчет управленческой зарплаты\Параметры расчета ЗП сотрудников" актуальными данными для расчета зарплаты.
4. Ввести  документ "Расчет управленческой зарплаты\График отпусков" на текущий год по всем сотрудникам.

### Права доступа
1. Добавить пользователю, ведущему расчет зарплаты и учет отпусков, права доступа "КадровикРасчетчик".
